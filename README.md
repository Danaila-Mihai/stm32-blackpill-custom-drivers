This is a personal attempt to implement a HAL for the STM32F401CCu6 
microcontroller, based on the following reference manual:
https://www.st.com/resource/en/reference_manual/rm0368-stm32f401xbc-and-stm32f401xde-advanced-armbased-32bit-mcus-stmicroelectronics.pdf

It serves primarily as a learning exercise for myself. References to the manual
will be included via comments, for cross-checking and revision purposes.
